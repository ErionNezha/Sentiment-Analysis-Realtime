# Sentiment Analysis Realtime

Analizë ndjenjash në kohë reale (streamlit + NLTK VADER): shkruan tekstin dhe merr vlerësimin Pozitiv/Negativ/Neutral me skor.

## ▶️ Live Demo
Hap `demo/index.html` në browser — ose shiko Live Demo-n në GitHub Pages.

## 📁 Struktura
- `index.html — faqja showcase (Live Demo + Kodi Burim)`
- `demo/index.html — demo web (simulim me leksik të ngulitur)`
- `original/main.py — kodi origjinal Python (i paprekur)`
- `README.md, PROVENANCE_LICENSE.txt`

## 🖥️ Si ekzekutohet origjinali
Kërkon Python + `pip install streamlit nltk`. Ekzekuto me `streamlit run main.py` — hapet në browser me fushën e tekstit dhe rezultatin.
